Put the map on your Edge

  1. Connect the Edge to a computer with a USB cable. Windows shows it in Explorer. On a Mac, an Edge 530, 830 or 1030 appears as a disk in Finder; an Edge 540, 840, 1040, 1050 or newer needs a file transfer app such as OpenMTP.
  2. Copy the downloaded .img file into the Garmin folder on the device. The file can have any name.
  3. Unplug the cable and wait for the Edge to restart.
  4. On the Edge, open the settings of the profile you ride with, go to Navigation, then Map, and switch the new map on in the list of maps.
  5. In the same Map settings, open Appearance and set Map Detail to Less. The map is drawn for that setting.
  6. Leave Garmin's own map switched on as well. This map is drawn on top; routes are still calculated by Garmin's map, because this one has no routing data.

Tried on an Edge 830 so far: labels, navigation and rerouting work. For other models the steps follow Garmin's manuals. If the map does not appear, switch Garmin's map off for a moment to check that the device reads the file.
